# Pinned distribution bases

These are unmodified upstream filesystem contents, not proprietary Termux Jobs distributions. Files retain their individual upstream licenses. License/copyright records are included in the images (usually `/usr/share/doc`, `/usr/share/licenses`, and distribution package metadata). The packaging recipe is GPL-3.0-or-later; corresponding packaging source and exact OCI source digests are included as release assets.

Upstream package sources and license information:
- Ubuntu: https://archive.ubuntu.com/ubuntu/ and https://ports.ubuntu.com/ubuntu-ports/ (source packages under pool; https://ubuntu.com/legal/open-source-licences).
- Debian: https://deb.debian.org/debian/ and https://www.debian.org/legal/licenses/.
- Alpine: https://gitlab.alpinelinux.org/alpine/aports and https://dl-cdn.alpinelinux.org/alpine/.
- Fedora: https://src.fedoraproject.org/ and https://docs.fedoraproject.org/en-US/legal/.
- openSUSE: https://build.opensuse.org/ and https://en.opensuse.org/openSUSE:License.
- Void: https://github.com/void-linux/void-packages and https://github.com/void-linux/void-containers.
- Kali: https://gitlab.com/kalilinux/packages and https://www.kali.org/docs/policy/kali-linux-open-source-policy/.
- Arch Linux ARM / Termux rootfs: https://github.com/archlinuxarm/PKGBUILDs and https://github.com/termux/proot-distro.
- Manjaro ARM: https://code.manjaro.org/ and https://github.com/manjaro-arm/rootfs.

No user-created phone environment, project, agent history, login token or SSH private key was used to create these base archives. They are not snapshots of the developer's configured phone.
